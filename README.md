# 📚 Student Records System

> A simple web-based student records management system built with **Vite**, **Vanilla JavaScript**, and **Supabase**.

---

## 📖 About This Project
This is a class project for IT3119 — Web Application Development. It demonstrates how to build a full-stack web application without using a complex frontend framework, connecting directly to Supabase for database and authentication services.

---

## ✨ Features
- 🔐 **Operator Authentication** — Sign up, sign in, email verification, and protected content
- 📝 **Student Records** — Create, read, update, and delete student information
- 🔍 **Search & Filter** — Find students by name or student number
- 📊 **Course Management** — Courses linked to academic departments
- 📈 **Enrollment Report** — Count students per course using a database function
- 📱 **Responsive Design** — Works on desktop and mobile browsers

---

## 🛠️ Built With
- **HTML5** — Page structure
- **CSS3** — Styling
- **Vanilla JavaScript (ES6+)** — Application logic
- **Vite** — Fast development server and build tool
- **Supabase** — PostgreSQL database, authentication, and API
